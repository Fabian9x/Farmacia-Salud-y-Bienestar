# Design System

## Direction

Una farmacia de barrio contemporánea vista a plena luz del día: precisa y limpia, pero cálida en el trato. La línea cardiaca del logotipo se convierte en una ruta visual que conecta cuidado, productos y contacto.

## Color

- Azul confianza: `oklch(0.43 0.15 251)`
- Azul profundo: `oklch(0.29 0.105 251)`
- Verde bienestar: `oklch(0.62 0.17 130)`
- Verde profundo: `oklch(0.43 0.13 130)`
- Fondo: `oklch(1 0 0)`
- Superficie suave: `oklch(0.97 0.012 240)`
- Tinta: `oklch(0.23 0.035 251)`

## Typography

- Titulares: Source Serif 4, con formas humanas que dialogan con el nombre del logotipo.
- Interfaz y cuerpo: Atkinson Hyperlegible, elegida por su alta diferenciación entre caracteres y lectura cómoda.

## Layout

Contenedor máximo de 1200 px, ritmo amplio y responsive. El hero usa una composición asimétrica 7/5; las listas funcionales se adaptan con CSS Grid. Bordes de 12 a 18 px y sombras discretas.

## Components

Botones sólidos de alto contraste, chips de filtro desplazables, tarjetas de producto uniformes, barra de servicios compacta y navegación sticky con estado de scroll.

## Motion

Transiciones breves con salida suave, elevación máxima de 4 px y escalado de imagen no mayor a 1.03. Todo se desactiva cuando el sistema solicita movimiento reducido.
